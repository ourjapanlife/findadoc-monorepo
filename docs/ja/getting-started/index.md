# はじめに

ようこそ！Find a Doc, Japanへの貢献を始める方法をご紹介します。

## ステップ1：コミュニティに参加する

[Slackワークスペース](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email)に参加し、**#general**または**#dev-team**で挨拶してください。手伝いたいことを教えていただければ、適切な方向をご案内します。

## ステップ2：開発環境を設定する

[コードの実行](../development/running-the-code.md)ガイドに従って、プロジェクトをローカルで実行してください。

**推奨IDEプラグイン**（VS Code向け）：

- [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) — リンティングの自動表示
- [Vue Official](https://marketplace.visualstudio.com/items?itemName=Vue.volar) — Vue 3 / Nuxtサポート
- [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) — Tailwindクラスの自動補完

## ステップ3：ブランチを作成してコーディング

1. 作業したいリポジトリをクローンし、`main`からブランチを作成してください — ユーザー名をプレフィックスにしてください：`yourusername/my-change`
2. コードを書き、すべての自動チェックとリンターがパスすることを確認してください
3. ブランチをプッシュし、GitHubでPull Requestを送信してください。変更内容とテスト方法を明確に記述してください

## ステップ4：コードレビュー

チームと一緒にPRをレビューし、マージしましょう。Slackの**#dev-team**で気軽に質問してください。

## オープンソースが初めてですか？

Git、GitHub、初めてのPull Requestの作り方については、[初心者向けリソース](beginner-resources.md)をご覧ください。
