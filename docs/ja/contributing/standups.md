# スタンドアップ

## 週次スタンドアップ

Find a Docでは定期的にスタンドアップを開催しており、コントリビューターは以下のことができます：

- 現在のタスクの進捗を共有
- 質問して助けを得る
- 他のコントリビューターと調整
- 今後の優先事項について学ぶ

## 参加方法

[Slackワークスペース](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email)に参加して、スタンドアップの時間とミーティングリンクの詳細を確認してください。スタンドアップ情報は**#dev-team**チャンネルで共有されます。

## 期待すること

スタンドアップはカジュアルで歓迎的な雰囲気です。ベテランコントリビューターでも、始めたばかりでも、ぜひ参加してください。
