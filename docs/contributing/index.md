# Contributing

Find a Doc, Japan is open source and built by volunteers. We welcome anyone willing to contribute their skills — no matter your background or experience level.

## Ways to Contribute

### Developers

Get started with the [Getting Started](../getting-started/index.md) guide, then follow the [Contribution Workflow](workflow.md). We welcome contributions to any of our [repositories](../index.md#repositories).

### Designers

Join **#dev-team** on [Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email) to help improve the user experience and interface design.

### Translators

Join the **#localization** channel on [Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email) to help translate the platform into more languages.

### Data Contributors

Our healthcare provider data is crowd-sourced. Help us grow the directory by submitting provider information through [findadoc.jp](https://www.findadoc.jp) or on [Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email).

### Other Skills

We also welcome help with legal, marketing, research, and anything else you can bring to the table. Join **#general** on [Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email) and let us know how you'd like to help.

## Giving Thanks

We use the [All Contributors Bot](https://allcontributors.org/) to celebrate all kinds of contributions — from code to design, research, translation, and more. Read about [how to use the bot](https://allcontributors.org/docs/en/bot/usage).
