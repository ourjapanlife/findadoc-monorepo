# 初心者向けリソース

オープンソースへの貢献が初めてですか？ようこそ — ご参加いただけて嬉しいです！

GitHubとGitに慣れるためのリソースをご紹介します。Find a DocのIssueに取り組む前に、1〜2つ確認することをお勧めします。

## Git & GitHubを学ぶ

- [Open Source Guide: How to Contribute](https://opensource.guide/how-to-contribute/) — オープンソースへの参加について学ぶ（英語）
- [First Contributions](https://github.com/firstcontributions/first-contributions) — 初めてのPRを作るハンズオンチュートリアル（英語）
- [Pull Requestの作成](https://docs.github.com/ja/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request) — GitHub公式ドキュメント

## 主要な概念

| 概念 | 説明 |
|---------|-------------|
| **クローン (Clone)** | リポジトリをローカルマシンにダウンロードすること |
| **ブランチ (Branch)** | 独立した開発ライン |
| **プルリクエスト (PR)** | メインプロジェクトに変更をマージするリクエスト |
| **コードレビュー** | マージ前にチームメンバーがPRをレビューすること |
