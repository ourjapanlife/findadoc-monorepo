# コントリビュート

Find a Doc, Japanはオープンソースであり、ボランティアによって構築されています。バックグラウンドや経験レベルに関係なく、スキルを活かして貢献したいすべての方を歓迎します。

## 貢献の方法

### 開発者

[はじめに](../getting-started/index.md)ガイドから始めて、[コントリビューションワークフロー](workflow.md)に従ってください。すべてのコードは1つの[リポジトリ](../index.md)にあります。

### デザイナー

[Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email)の**#dev-team**に参加して、ユーザー体験やインターフェースデザインの改善にご協力ください。

### 翻訳者

[Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email)の**#localization**チャンネルに参加して、プラットフォームをより多くの言語に翻訳するお手伝いをしてください。

### データ提供者

医療機関データはクラウドソーシングで収集しています。[findadoc.jp](https://www.findadoc.jp)または[Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email)を通じて医療機関情報を提供し、ディレクトリの拡大にご協力ください。

### その他のスキル

法務、マーケティング、リサーチなど、あらゆるスキルでの貢献を歓迎します。[Slack](https://find-a-doc.slack.com/join/shared_invite/zt-2lb3j2t1z-O9F4thzcFktqsIXNzzjzHw#/shared-invite/email)の**#general**に参加して、どのように貢献したいかお知らせください。

## 感謝の表明

[All Contributors Bot](https://allcontributors.org/)を使用して、コード、デザイン、リサーチ、翻訳など、あらゆる種類の貢献を称えています。[ボットの使い方](https://allcontributors.org/docs/en/bot/usage)についてはこちらをご覧ください。
