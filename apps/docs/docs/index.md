# Welcome to Find a Doc, Japan!

This is a crowd-sourced platform to help people find healthcare in their language.

We're happy to have you check out or even join our project! We are a non-profit organization focused on building products that improve the lives of people living in Japan.

**Why does this project exist?** Have you or a friend ever needed to find a doctor, but you don't speak fluent Japanese? Maybe you're just visiting Japan and need some quick help. This project helps with that — it's a crowd-sourced website to help people find healthcare in their language.

To learn more about the team and the history, check out our [about page](https://www.findadoc.jp/about).

!!! info "Looking for healthcare services?"
    This site is for **developers and contributors**. If you're a patient looking for healthcare in your language, or a healthcare professional looking to list your practice, please visit [findadoc.jp](https://www.findadoc.jp).

## Repository

All of our software is open source and lives in one monorepo: [findadoc-monorepo](https://github.com/ourjapanlife/findadoc-monorepo).

| Path | Description |
|------|-------------|
| `apps/web` | Website at [findadoc.jp](https://www.findadoc.jp) (Nuxt 4 / Vue 3) |
| `apps/server` | GraphQL API (Node.js / Apollo Server / Supabase) |
| `apps/mcp` | MCP server for AI integrations |
| `apps/docs` | This documentation site |
| `packages/graphql` | TypeScript types generated from the API schema |
| `packages/utils` | Shared checks and helpers used by the site and the API |
